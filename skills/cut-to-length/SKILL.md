# Cut to Length

A hard limit changes the job. General editing makes prose better; this makes it fit. Every cut is a trade, so cut in order of least loss and stop when you reach the target.

## Procedure

1. **Measure.** Count the draft in the unit the user named (words, characters with or without spaces, lines, pages at a stated format). State the count and the target before cutting.
2. **Cut in passes, cheapest first.** Stop as soon as you reach the target.
   - Pass 1 — needless words: "in order to", "the fact that", hedges, intensifiers, doubled modifiers, "there is/are" constructions.
   - Pass 2 — redundancy: points made twice, examples that illustrate the same thing, summaries that repeat the body, transitions that announce what the next sentence already shows.
   - Pass 3 — compression: passive to active, verb-noun pairs to verbs, two sentences sharing one idea merged, lists of three that work as two.
   - Pass 4 — subordination: supporting detail folded into the main clause or dropped. Prefer dropping an example to dropping a claim.
   - Pass 5 — content: whole points removed. Do this only when passes 1–4 fall short, and name every point you removed.
3. **Re-measure.** Confirm the result meets the target. If the target was a page, state the assumed font, size, and margins.
4. **Report.** Give the cut text, the before and after counts, and what left in pass 5, if anything.

## Rules

- Keep every claim, number, name, and commitment unless pass 5 forces a choice. Then the user decides; say what you removed and why it was the cheapest loss.
- Keep the voice and register. A cut cover letter should still sound like the person who wrote it.
- Keep required elements: salutations, signatures, legal lines, dates, reference numbers.
- Cut evenly when the text has sections of equal weight. Do not gut the conclusion to spare the opening.
- Respect the user's unit. "Under 300 words" means the result counts at 299 or fewer in the way they will count it. When the counting method matters (hyphenated words, numbers, headings), state the one you used.
- Never pad. If the draft already fits, say so and offer a line edit instead.

## Output

```
**Before:** 412 words · **Target:** ≤300 · **After:** 296

[Cut text]

**Removed in pass 5** (only if used)
- The paragraph on the 2024 pilot (41 words). It supported a claim already made by the Q3 figures.
```

For a percentage target ("cut by a third"), compute the number and show it: "412 words → target ≤275 → 268."
